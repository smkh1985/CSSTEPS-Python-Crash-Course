# Lesson 6: User Input and List Operations

## Your turn

Your turn: write a small program for a reading club. Start with an empty list called books, and ask for two titles. Append each title as soon as the user enters it. Then ask for a third title, and the index where it should go. Convert the index to an integer, insert the title, and print the list. Pause the video and try it.
